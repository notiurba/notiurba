# Skills globales usadas en NotiUrba

Copias de las skills que se crearon trabajando en este proyecto y sirven en otros. Para usarlas en otra cuenta o
equipo, copie cada carpeta a `~/.claude/skills/`:

```bash
cp -r docs/skills-globales/linear-historias-sprint docs/skills-globales/traspaso-de-sesion ~/.claude/skills/
```

| Skill | Para qué |
| --- | --- |
| `linear-historias-sprint` | Planear un sprint y crear historias en Linear con el formato del equipo; qué hacer por el navegador cuando la API no alcanza. |
| `traspaso-de-sesion` | Cerrar una sesión larga actualizando documentación, vault, memoria y skills. |

La skill propia de este repo (`notiurba-pruebas-y-despliegue`) vive en `.claude/skills/` y `auditar-pr` ya estaba en `~/.claude/skills/`.
